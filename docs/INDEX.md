# Documentation du projet

Le produit actuel est un TCG shinobi jouable dans le navigateur, centré sur la collection et l'amélioration de cartes. La documentation peut contenir des valeurs ou descriptions héritées : le code et les catalogues actuels font foi, en particulier pour les effets de cartes, les statistiques des ninjas et l'équilibrage.
