# Game rules (player)

Content shown in the UI (`/rules`) is maintained here:

- **FR**: [`frontend/src/content/rules.fr.md`](../frontend/src/content/rules.fr.md)
- **EN**: [`frontend/src/content/rules.en.md`](../frontend/src/content/rules.en.md)

## Structure

1. **Part 1 — The interface**: screen guide grouped like the navigation menu (Command center, Squad & progression, Missions & league, Economy, Account & tools).
2. **Part 2 — Game systems**: detailed rules (cycle, ninjas, deck, training, missions, reconnaissance, economy, league, operation…).

When updating rules, edit those files (they are included in the frontend Docker build).
