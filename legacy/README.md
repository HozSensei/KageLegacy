# Legacy Code Archive

Ce dossier contient le code de l'ancienne version de Kage Legacy (système de gestion d'escouade Hattrick).

## Raison du déplacement

Kage Legacy V2 transforme le jeu en **deck-building roguelike** avec un personnage unique.
L'ancien système de gestion d'escouade de ninjas n'est plus nécessaire.

## Contenu archivé

### Backend Services
- Squad management (composition, tactiques)
- Ninja recruitment & generation
- Academy & training system
- Old combat system (pre-cards)
- League & rivalry
- Player market (ninja trading)
- Operations & reconnaissance
- Bureau items & dispensary
- Bird Flight & Chunin exams
- Clan system
- Village rivalry
- Elite subscription (old monetization)

### Frontend
- Squad management UI
- Ninja cards & profiles
- Market views
- Training panels
- Bureau panels
- League views
- Operation views

## Ce qui est conservé

- Auth system (users, sensei table)
- Database configuration
- Middleware
- Base game clock
- Stripe integration (pour futur Battle Pass)

## Date d'archivage

Novembre 2026 - Phase 0 de Kage Legacy V2

---

**Note** : Ce code est conservé pour référence historique mais ne doit pas être utilisé dans V2.
